Why it exists

Most parental-control tools ask you to hand a stranger's cloud service your family's traffic. UniFi's firewall already does everything a tool like that promises — it's just buried three menus deep, in an interface built for network admins, not for "can I have ten more minutes."

KindFi doesn't add a new system. It just puts the rules you already wrote somewhere you'll actually reach for them — grouped by person, one tap to toggle, nothing sent anywhere but your own router.

What you'll need

  • iOS 17.0 or later
  • A UniFi Dream Machine or Cloud Gateway with UniFi Network 8.x+ and zone-based firewall policies enabled
  • A local UniFi admin account — not a Ubiquiti cloud login
  • Firewall rules already set up in the UniFi console (KindFi toggles them; it doesn't create them)
